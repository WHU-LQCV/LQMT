# 计算方法说明（LQMT v1.0.1）

本文面向需要核对算法、撰写对齐报告或二次开发的读者。日常下载与使用见仓库首页与 [user-manual.md](user-manual.md)。

对齐报告请写明：**LQMT v1.0.1**，并以本仓库 tag `v1.0.1` 的源码为准。

## CCT

本版本 CCT 使用 LuxPy 的 Ohno 2014 / Robertson 2023 路径。报告中请同时写明算法名称与 LQMT tag。

## CQS / Qa

MCPI 使用 CQS Qa。本版本调用 LuxPy `version='v9.0'`（LuxPy 1.12.5）。

课题组 SPD 数据集实测与 CQS 9.0.3 官方 Excel 一致度 99.7%（1009 条光谱对照，平均绝对差 0.003）。

## Sneutral 观察者

本版本 Sneutral 使用 CIE 1964 10°（Smet 模型原始定义）。对齐报告请按本 tag 口径注明观察者。

## Ra 取整

Ra 按 CIE 13.3 / GB/T 26180 报出口径：对 8 个特殊显色指数 Ri **取整后再算术平均**。

## Rd 色样表

`metrics/Rd.csv` 对齐 Esposito 工具 RefData2 全精度后插值到 380–780 nm / 5 nm。来源链见 [NOTICE](../NOTICE)。

## 激发纯度 p_e

界面和导出列名写作 `p_e (D65)`，用来标明无彩色点是 D65。结果页和配置页另有一句说明：无彩色点为当前观察者下的 CIE D65。微软雅黑没有 Unicode 下标字形，所以不用 pₑ。其余指标名称保持原样。

定义见 CIE S 017:2020 条目 17-23-066（IEC 60050-845:1987 的 845-03-48）：色品图上两段共线距离之比 NC/ND。C 是光源色品，N 是指定无彩色刺激，D 是射线 NC 与光谱轨迹的交点。

本版本把 N 取为同一观察者下的 CIE D65。三刺激值来自 LuxPy 全波段 D65（360–830 nm）的相对化结果，不随样品波长范围改变。CIE 1931 2° 下约为 x = 0.3127、y = 0.3290；CIE 1964 10° 下约为 x = 0.3138、y = 0.3310。h_ab 使用的是插到样品网格上的 D65，和这里的 N 不是同一个三刺激值。

紫色刺激（注 1）的 D 取紫边界，不取光谱轨迹；LuxPy 把对应主波长记为负值，pe 仍是到该交点的距离比。

注 2 的两个公式

pe = (y − yn) / (yd − yn) = (x − xn) / (xd − xn)

在 C、N、D 共线时等价。实现采用同一射线上的欧氏距离比，避免某一轴分母接近 0。单位为 1（注 4），不乘 100。

观察者跟随界面 CMF（CIE 1931 2° 或 CIE 1964 10°），光谱轨迹和 D65 色品使用同一套色匹配函数。CIE 1931 2°、380–780 nm / 5 nm 网格下，标准照明体 A 约为 pe = 0.5967，主波长约 584.0 nm。色品与上述 D65 重合时 pe = 0。

## 光源色调角 h_ab

界面和导出列名写作 `h_ab`。

CIE 1976 a*b* 色调角：

hab = atan2(b*, a*)

负值加 360°，结果落在 [0, 360)，单位为度。

CIELAB 是物体色空间。这里仍按要求硬算：光源 SPD 用 `spd_to_xyz(relative=True)` 得到 Y = 100 的 XYZ，参考白为同一观察者、同一波长网格上的 CIE D65，再调用 LuxPy `xyz_to_lab` 与 `math.positive_arctan`。样品在计算前会补齐到 380–780 nm，D65 也插到这条网格上，两端之外按 0 处理。因此每条光源的 L* 都是 100，hab 只表示该色品相对这套 D65 在 a*b* 平面上的方向。色品正好落在该 D65 上时 a* = b* = 0，色调角无定义，界面显示为「—」。

若改用 LuxPy 全波段 D65（360–830 nm）作白点，一条只覆盖 380–780 nm 的 D65 会留下大约 0.016 的 CIELAB 彩度，色调角没有意义。

CIE 1931 2°、380–780 nm 网格下，标准照明体 A 约为 hab = 68.33°。同网格上的 D65 为无定义。

## 范围

- 本工具计算光源光谱的颜色质量指标，不覆盖眩光、频闪、照度均匀性等其他维度。
- 请以 GUI 计算结果为准。
